# Margin vs. Markup Checker

A single-page calculator for small businesses. Enter an item's **cost** and **selling price** (in RM) and it shows the **gross margin** and the **markup** side by side.

- **Margin** = profit ÷ selling price
- **Markup** = profit ÷ cost

The page also includes a bar diagram showing why the two figures differ, and a conversion table of common margins and the markup each one needs.

## Use it

Open `index.html` in any browser. It has no build step and no dependencies apart from Google Fonts.

To host it for free, enable **GitHub Pages** for this repository (Settings → Pages → Deploy from branch → `main` / root).
